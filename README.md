# Doctors Portfolio — 100 Medical Website Templates

A complete showcase and demonstration platform featuring **100 handcrafted, specialty-focused doctor portfolio templates** for physicians, surgeons, dentists, and healthcare practices.

## 🚀 Instant Vercel Deployment Guide

Deploying this project to **Vercel** takes less than 1 minute:

### Method 1: Using GitHub + Vercel (Recommended)
1. Push this repository to your GitHub account (`git init`, `git add .`, `git commit -m "Initial commit"`, `git push`).
2. Go to [Vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your GitHub repository `doctors-portfolio`.
4. Leave all settings as default (Framework Preset: **Other**) and click **Deploy**!
5. Your website will be instantly live on a global fast CDN with free SSL (e.g. `https://doctors-portfolio.vercel.app`).

### Method 2: Using Vercel CLI
In your terminal, run:
```bash
npm i -g vercel
vercel
```

## 📁 Project Structure

- `index.html` — The main showcase gallery with real-time 18+ specialty filters, 8 layout filters, search, pricing packages, and WhatsApp integration (`+880 1609-977377`).
- `preview.html` — The live interactive device simulator (Desktop, iPad, iPhone frame switcher) with next/prev navigation.
- `templates/` — All 100 complete, self-contained doctor portfolio HTML templates (`template-001.html` through `template-100.html`).
- `vercel.json` — Pre-configured routing, clean URLs, and CORS frame permissions for smooth Vercel deployment.
